Tableau测试系统安装部署

📅 2025年10月15日 ⏱️ 阅读时间：20分钟

一、安装前准备

系统要求

  • 操作系统：Linux（推荐RHEL/CentOS）
  • 内存：至少16GB
  • 磁盘空间：至少50GB
  • 网络：需要能够访问互联网

二、TSM初始化

1. 创建用户账号

useradd admin
passwd admin

2. 运行初始化脚本

cd /opt/tableau/tableau_server/packages/scripts.xxxx/
sudo ./initialize-tsm --accepteula -a admin
💡 注意：

Tableau Server需要可以直接访问Internet，或者配置离线激活。

三、激活并注册Tableau Server

1. 访问TSM Web界面

打开浏览器并输入Tableau Server URL，例如：https://server-ip:8850

2. 激活许可证

使用许可证密钥进行激活：

  • Creator许可证
  • Explorer许可证

3. 离线激活

如果防火墙限制，可以进行离线激活：

  1. 创建脱机文件
  2. 上载脱机文件，下载激活文件
  3. 上载激活文件
  4. 创建、上载和提交第二个脱机文件
  5. 上载第二个激活文件

4. 注册

填写注册信息，点击初始化按钮，约15分钟后完成。

四、创建管理员账号

tabcmd initialuser --server 'localhost:80' --username 'admin'

使用此账号访问Tableau Server管理网页。

五、验证安装

1. 安装PostgreSQL驱动

sudo yum install tableau-postgresql-odbc-09.06.0500-1.x86_64.rpm

2. 登录验证

访问http://server-ip/，使用管理员账号登录验证安装成功。

六、配置HTTPS访问

SSL证书要求

  • 从受信任的颁发机构获取Apache SSL证书
  • 证书文件必须是有效的PEM编码X509证书，扩展名为.crt
  • 使用SHA-2（256位或512位）SSL证书
  • 需要对应的SSL证书密钥文件（.key扩展名）
  • 需要SSL证书链文件（.crt扩展名）

启用SSL步骤

  1. 在浏览器中打开TSM：https://server-ip:8850
  2. 在"配置"选项卡上，选择"安全" > "外部SSL"
  3. 选择"服务器服务器通信启用SSL"
  4. 上载证书和密钥文件
  5. 点击"保存未完成的更改"
  6. 点击"应用更改并重新启动"

七、后续配置

中文语言包支持

yum install fontconfig mkfontscale
yum install m17n-db-chinese
vi /etc/locale.conf
LANG="zh_CN.UTF-8"
source /etc/locale.conf

添加HANA驱动

mkdir -p /opt/tableau/tableau_driver/jdbc
cp ngdbc.jar /opt/tableau/tableau_driver/jdbc/
chmod 755 /opt/tableau/tableau_driver/jdbc/ngdbc.jar
tsm stop
tsm start

八、总结

Tableau Server安装部署需要按照步骤依次进行：TSM初始化、激活注册、创建管理员、验证安装、配置HTTPS、后续配置。每个步骤都需要仔细操作，确保安装成功。
